# antochuanchuan

**无需自建服务器的房屋照片风险辅助识别网页。**

用户打开静态网站 → 选择房屋照片和可选小区位置 → 浏览器直接调用用户选定的视觉模型（BYOK，需浏览器端支持 CORS）→ 得到 4 类照片可见事实 → 浏览器内检索公开证据目录、合成风险报告 → 页面展示分层证据和导出结果。

照片不能证明甲醛含量、承重墙性质、房产所有权和合同真实性。本项目给的是**未校准的风险规则符合度**，不是可验证的“串串房概率”。公开资料未匹配也不能视为“无风险”。

## 关键边界

- **零自建服务器**：不允许 FastAPI、SQLite、云函数、图片中转上传、后台任务轮询。图片处理、证据检索、风险合成在浏览器内完成。
- **模型联网**：真实 AI 分析会把图片发往第三方模型；需用户知情，并使用自己的 Key。首选验证 Gemini 直连；是否支持取决于实际浏览器 CORS 测试，不得提前承诺其他模型都能用。
- **BYOK 安全**：Key 默认只在当前页面内存，不能写入 localStorage、URL、日志或仓库。浏览器暴露的 Key 不具备服务器级秘密保护，建议使用独立限额 Key。
- **公开证据**：B 的合法资料要有来源；合成记录仅作显著标注的演示，不得假装真实。
- **不强行判断**：无法看到或来源不明时显示 `unknown` 或“证据不足”；风险分数不是经数据校准的真实概率。
- **无 Key 演示**：Mock 模式可离线演示数据和结果展示；真实 AI 需要网络和用户自己的 Key。
