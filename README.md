# antochuanchuan

**一个无需自建服务器的房屋照片风险辅助识别网页。**

上传照片 → 在浏览器中直接调用用户选择的大模型（用户提供 Key）→ 从照片提取可见特征 → 浏览器本地计算未校准的装修风险符合度 → 展示证据与建议。

> 注意：本工具不能诊断甲醛超标、产权、承重墙属性、合同真实性等非照片可见问题，也不能仅凭照片确诊“串串房”。“整租/合租”和“装修风险”是两个不同维度。

## 技术方向

- React + TypeScript + Vite，构建为静态 HTML/CSS/JS。
- 前端直接调用**经实测支持浏览器访问**的视觉模型服务（优先验证 Gemini）。
- 使用 Zod 校验视觉模型的 JSON；模型只识别可见事实，使用 `present/absent/unknown`。
- 浏览器本地评分，不经过自建 API 或数据库。
- Key 默认仅放页面内存，不放 LocalStorage、URL、日志或仓库。照片在用户授权分析时发送给第三方模型服务商。
- Mock 模式可无 Key 体验；真实 AI 分析需要网络和用户自行提供的模型 Key。
