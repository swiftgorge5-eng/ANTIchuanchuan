# 高德地图选点：Key 申请与配置

## 1. 去哪里申请

1. 注册/登录高德开放平台：https://console.amap.com/dev/id/choose
2. 完成**实名认证**（个人或企业）：https://console.amap.com/dev/user/permission
   - 未认证无法创建 Key。
3. 进入「应用管理 → 我的应用」：https://console.amap.com/dev/key/app
   - 点「创建新应用」，填应用名（例如 `antochuanchuan`）、类型选「出行」或「生活服务」。
4. 在该应用下点「添加 Key」：
   - **Key 名称**：随便填，例如 `web-jsapi`
   - **服务平台**：必须选 **Web端(JS API)**，不要选 Web服务 / Android / iOS
   - 勾选需要的服务，提交后得到 **Key**。
5. 在 Key 详情里复制**安全密钥（securityJsCode）**。
   - 2021-12-02 之后申请的 Key 必须配合安全密钥使用，否则地图会报 `INVALID_USER_KEY` / `USERKEY_PLAT_NOMATCH`。
6. （推荐）在该 Key 下配置**域名白名单**：开发期加 `localhost` 和 `127.0.0.1`；上线后加真实域名。
   - 白名单留空时高德默认不做域名限制，但 Key 容易被盗用。

## 2. 填到哪里

在**项目根目录**（与 `package.json` 同级）新建 `.env.local`：

```
VITE_AMAP_KEY=你复制的Key
VITE_AMAP_SECURITY=你复制的安全密钥
```

- `.env.local` 已被 `.gitignore` 里的 `*.local` 忽略，**不会进版本库**。
- 仓库里的 `.env.example` 是模板，不要直接改它填真 Key。
- 改完必须**重启 `npm run dev`**：Vite 只在启动时读取环境变量。
- 只允许 `VITE_` 前缀的变量暴露给前端。**这是公开变量**，任何人打开页面都能看到 Key，这是高德 JS API 的正常设计，靠域名白名单限制滥用，不要试图在纯前端「隐藏」它。

## 3. 没有 Key 会怎样

页面照常工作：小区查询、照片示例报告、历史记录都不受影响。点「定位找小区」或「在地图上选点」会弹出地图面板并在底部提示去配置 Key；「使用当前位置」会提示拿不到位置，可以直接手动填写小区名。

## 4. 这个功能做什么、不做什么

- **做**：拖动地图 → 准星对准的小区被识别出来（高德逆地理编码，优先返回小区面 `aois`，并用周边住宅 POI 交叉验证）；点「定位」用浏览器定位并在图上打一个蓝点，画面回到本人位置；搜索小区名直接把地图移过去；选好后把小区名带回「小区标签」或小区查询。
- **不做**：把经纬度写进报告。报告契约 `FinalReport` 没有坐标字段，加字段要改 `docs/interfaces.md`，需要 A 批准。定位结果只用于确认地点。
- **边界**：地理匹配不是风险证据；同名小区仍需人工核对；识别结果可能落在「只命中兴趣点」甚至「只有门牌号」，界面会明确标注是哪一档。
- **隐私**：只有用户主动打开地图或点定位时才请求高德；不会把照片、Key、地址线索发给高德。

## 5. 常见报错

| 现象 | 原因 |
|---|---|
| `INVALID_USER_KEY` | Key 填错，或服务平台不是「Web端(JS API)」 |
| 地图灰屏 + 控制台 `USERKEY_PLAT_NOMATCH` | Key 用了 Web 服务类型 |
| `INVALID_USER_DOMAIN` | 域名白名单里没有当前地址 |
| 地图能出来但没有小区名 | 该点只有门牌地址，换个位置或放大再拖 |
| 点「定位」没反应 | 非 https/localhost，或浏览器拒绝了定位权限 |

## 6. 白名单与本地开发的坑

白名单一旦填了，**就只认白名单里的域名**：`localhost`、`127.0.0.1`、`file://` 都会报 `INVALID_USER_DOMAIN`（地图面板会显示“高德地图脚本加载失败”）。

两种做法，选一种：

| 做法 | 做法细节 | 适合 |
|---|---|---|
| **双 Key**（推荐） | Key A 给线上，白名单只填 `swiftgorge5-eng.github.io`；Key B 给本地，白名单留空 | 本地和线上都要用 |
| 单 Key 加白名单 | 白名单里同时填 `swiftgorge5-eng.github.io` 和 `localhost`（部分版本不接受端口和 IP） | 只在一台机器上开发 |

验证白名单是否生效：让另一台没登录过你账号的电脑打开页面，地图应当报 `INVALID_USER_DOMAIN`；报错说明白名单确实在拦。改完白名单通常几秒到几分钟生效，验证前先强刷（Ctrl+F5）。
